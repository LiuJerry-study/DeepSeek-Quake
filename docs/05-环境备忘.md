# 环境备忘（特定机器上的坑）

> 从原 README 拆分而来：**只有在遇到对应现象时才需要看**。
> 普通机器上双击 exe 就能用，用不到这一篇。
> ### 启动方式（重要：没有「桌面快捷方式」）
>
> 项目里**没有** `.lnk` 快捷方式。启动就这几种，任选：
>
> | 方式 | 怎么做 |
> |---|---|
> | **最简单** | 进 `D:\Desktop\DeepSeek Quake` 文件夹，**双击 `DeepSeekQuake.exe`** |
> | 脚本 | 双击 **`start-deepseek.cmd`**（内容就是 start 一下上面那个 exe） |
> | 自建桌面快捷方式 | 见下方「想要桌面快捷方式」 |
>
> **不要**用 `DeepSeekChrome.lnk`（它只开浏览器窗口，不启动小工具），
> 也不要用 `backup\DeepSeek Quake-tool.lnk`（指向旧版 exe）。
>
> **想要桌面快捷方式**：在 PowerShell 里粘这一行（桌面是 `D:\Desktop`）：
>
> ```powershell
> $s=(New-Object -ComObject WScript.Shell).CreateShortcut('D:\Desktop\DeepSeek Quake.lnk'); $s.TargetPath='D:\Desktop\DeepSeek Quake\DeepSeekQuake.exe'; $s.WorkingDirectory='D:\Desktop\DeepSeek Quake'; $s.IconLocation='D:\Desktop\DeepSeek Quake\DeepSeekQuake.exe,0'; $s.Save()
> ```
>
> ### 本机环境备忘（踩过的坑）
>
> - **本机没有托盘图标**：`Shell_TrayWnd` 存在但 `ToolbarWindow32=无`（Themia 自定义外壳），
>   通知区域没地方放图标。所以**托盘菜单/托盘右键全部不可用**，改设置和看诊断只能用
>   `Ctrl+Alt+S` / `Ctrl+Alt+D`，退出只能用任务管理器。
> - **本目录曾被打了 Low 完整性标签的强制继承**，导致在这里新建的文件（包括刚编译的 exe）
>   都自动是 Low，启动时弹「检测到低完整性」并拒绝运行。**该问题已修复**：目录现在是
>   Medium。如果以后再遇到，跑 `pwsh -File src\fix-integrity.ps1`（在**目录**上改标签，
>   逐个改文件无效）；`src\build.ps1` 现在也会自检产物标签，发现是 Low 会直接报错。

1. 双击 **`DeepSeekQuake.exe`**（或 `start-deepseek.cmd`）。
2. 屏幕上会立刻出现一个**启动状态窗口**，逐条显示进度：

   ```
   ✓  小工具已在运行
   …  正在查找 / 启动 DeepSeek 窗口
   …  热键要等窗口就绪后才启用
   ```

3. **等这个状态窗口自己关闭**——它消失才代表已经锁定浏览器窗口、热键才武装。
4. **连按两下 Ctrl** 收起 / 呼出。
5. 窗口里点右键 = 粘贴；Shift+右键 = 原生菜单。
6. 改设置：**Ctrl+Alt+S**；看诊断：**Ctrl+Alt+D**。
7. 退出：任务管理器结束 `DeepSeekQuake.exe`，或命令行 `taskkill /IM DeepSeekQuake.exe`
   （本机没有托盘，所以没有「托盘退出」这条路）。

> 如果浏览器没起来，状态窗口**不会**一闪而过——它会停在那里，
> 标题变成「启动没有成功」，写出具体原因，并给出「重试启动 / 设置… / 自检与诊断…」三个按钮。


### 你的机器上没有任务栏 / 托盘图标（重要）

小工具会**自动检测**系统有没有任务栏和通知区域：

- 有任务栏 → 正常显示托盘盾牌图标，双击 = 呼出/收起，右键 = 菜单；
- **没有任务栏**（例如 explorer.exe 没在运行、或用了 Themia 这类自定义桌面外壳）
  → 托盘图标无处可放，小工具改用**热键**作为全部入口：

  | 热键 | 作用 |
  |---|---|
  | 双击 Ctrl | 呼出 / 收起 |
  | `Ctrl+Alt+S` | 打开设置 |
  | `Ctrl+Alt+D` | 打开自检与诊断 |

  这三个键都能在 `hotkey.conf` 里改（`hotkey` / `settingshotkey` / `diagnosehotkey`）。

启动没成功时可以依次试：

- 状态窗口里点「**重试启动**」；
- 双击 **DeepSeekChrome.lnk** 手动把浏览器窗口打开，小工具会自动接管它；
- 把 `D:\Desktop\DeepSeek Quake` 加进火绒信任区（火绒主界面 → 右上角菜单 → 信任区 → 添加目录）；
- 小工具是单实例程序，任务管理器里如果有卡住的 `DeepSeekQuake.exe`，先结束掉。

**双击 Ctrl 完全没反应时（重点）**：

- 先确认小工具不是被自动化脚本、沙箱或任务计划启动的。Windows 会把这类启动
  标成「低完整性」，并阻止它收到普通键盘输入——此时任何全局热键都不可能生效。
  最明显的特征是诊断串里出现 `il=low`，或启动时弹出「低完整性」警告。
- 处理办法：任务管理器里结束所有 `DeepSeekQuake.exe`，然后**从资源管理器双击
  `DeepSeekQuake.exe`** 正常启动。不要用 `Start-Process`、WMI、计划任务或 CI
  拉起常驻实例。
- 窗口可见时按热键一定先收起（即使它不在前台、被别的窗口盖住）——这就是标准
  quake 终端的行为。收起后窗口不在任务栏也不在 Alt+Tab，再按一次会重新显示并
  尽量提到前台；提不到时会先临时置顶再取消置顶兜底，不会卡在「看得见但点不到」
  的死角。
